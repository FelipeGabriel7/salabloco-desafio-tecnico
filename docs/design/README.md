# Design

Definições visuais do Salabloco.

## Cores

| Uso | Valor |
| --- | --- |
| Ação (verde-petróleo) | `#0F766E` |
| Ação suave (item ativo) | `#E2F1EF` |
| Texto | `#1C2523` |
| Fundo | `#F7F6F3` |
| Aviso (âmbar) | `#B45309` |
| Salas | Uma cor por sala: `#2563EB`, `#7C3AED`, `#65A30D`, `#A16207`, `#BE185D` |

Há também tema escuro. Os tokens de cor (claro e escuro) ficam em `apps/web/src/index.css`.

## Tipografia

- **Títulos:** Manrope.
- **Texto:** Inter.
- **Horários:** números tabulares.

## Forma

- Raio de 10 px em botões e campos, 14 px em cartões.
- Logo: quadrado verde com dois blocos de horário deslocados.
